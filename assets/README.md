# DuckbillCalendar 대표 아이콘

사용자가 선택한 최종안: 달력을 바라보는 자연스러운 자세(v7-natural).
- duckbillcalendar-icon.png: 적용/배포용 512×512 투명 PNG
- source/duckbillcalendar-icon-master.png: 선택한 생성 원본
- previews/duckbillcalendar-128.png / duckbillcalendar-64.png: 축소 확인용
- icon-prompt.txt: built-in image_gen 최종 편집 프롬프트

기존 Fisher/Tweak 아이콘을 캐릭터/스타일 참조로 제작했다. 원본 alpha를 보존하여 크기를 정규화했다.
README와 설치 manifest의 IconUrl, 로컬 images/icon.png는 같은 대표 PNG를 사용한다. 원격 게시하지 않았다.
Fisher/Tweak 선택본 사본과 제작 기록은 버전관리에서 제외한 artifacts/icon-handoff/에 정리했다. 타 프로젝트에는 아직 반영하지 않았다.
이전 시안·중복 비교본·이전 원본은 artifacts/design-archive/에 SHA256 검증 ZIP으로 보존한다.
