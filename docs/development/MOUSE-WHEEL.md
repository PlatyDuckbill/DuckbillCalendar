# 달력 마우스 휠

2026-11-13. 월간 달력의 날짜 격자 위에서 휠을 올리면 이전 달, 내리면 다음 달로 이동한다. 한 눈금은 한 달이며 트랙패드의 분수 입력은 누적한다. 한 프레임의 이동은 최대12개월이고2020년1월~2100년12월 범위를 넘지 않는다.

날짜 격자 밖의 목록·상세 패널은 기존 스크롤을 유지한다. 팝업·편집 중이거나 Ctrl/Shift/Alt를 누르면 달력 월 이동을 적용하지 않는다. 달력은 자체 child 영역과 SDK가 제공하는 ImGui1.88의 wheel 사용 등록을 사용해 창 본체가 동시에 세로 스크롤되지 않게 한다.

Native ImGui에서1/1.5/2배율마다 이전/다음 달, 분수 누적, 격자 밖, Ctrl, 팝업, 부모 스크롤 분리, 연도 양 끝을 검사했다.27개 추가로 native111검사, 전체475검사·한영182쌍이다. GPU·실제 게임 화면의 시각 확인과 구분한다.
