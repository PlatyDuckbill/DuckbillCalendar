# 달력의 일정 찾기

2026-11-14 로컬 개발 변경. 별도 새소식 화면을 달력 검색으로 통합한다.

## 사용자 동작

달력의 검색 버튼으로 검색 팝업을 열고 이름 일부나 버전 번호를 입력한다. 팝업은 검색 버튼 아래를 기준으로 화면 안에 위치하며 달력 크기와 위치를 바꾸지 않는다. 작은 화면에서는 결과를 팝업 안에서 스크롤한다. `백은` 또는 `백은 언제 열리지?`는 번들의 정식 출시·앞서 해보기·예약 기간을 각각 찾는다. 정식 출시와 앞서 해보기를 구매 캠페인보다 먼저 보여준다. 현재 표시 중인 월 밖도 검색하며 검색 입력 자체는 달력을 다른 날짜로 이동하거나 일정 필터를 바꾸지 않는다.

날짜가 있는 결과를 누르거나 Enter로 첫 결과를 선택하면 해당 월과 날짜로 이동하고 일별 팝업에서 선택한 일정을 강조하며 검색 팝업은 닫는다. 선택 날짜 칸은 강조색 테두리·배경·날짜 배지로 표시하고 해당 행이 보이도록 스크롤한다. 일별 팝업을 닫아도 선택 강조를 유지한다. 지우기는 검색어와 결과를 비우고 입력창을 유지한다. Escape나 바깥 클릭으로도 닫는다. 공식 링크 아이콘은 날짜 이동과 별개로 실제 연결된 공식 안내를 연다. 연결이 없는 항목에는 링크 버튼을 만들지 않는다. 날짜 미정인 행은 이동 버튼을 만들지 않는다.

숨긴 일정도 검색한다. 이를 선택하면 해당 날짜의 팝업에서 선택한 단계만 임시로 열어 본다. 개별 일정·분류의 숨김 설정을 변경하지 않는다.

검색 버튼은 설정·알림 등 메인 화면에서도 같은 위치에 유지한다. 누르면 달력으로 전환해 검색 팝업을 연다. 설정 톱니 재클릭 시 선택 날짜를 보존해 달력으로 돌아오는 동작과 전체 상단 도구의 좌표 유지, 설정 화면에서 실제 검색 버튼 클릭을 native 검사로 확인한다.

## 검색 범위와 처리

`CalendarSearch`는 현재 feed와 활성 계정의 개인 일정으로 만든 Events에서 CalendarContentPolicy가 허용하는 단계만 검색한다. 공지 게시일은 일정 날짜로 사용하지 않는다. 제목, 단계 이름, 분류 이름을 검색하고 유니코드·대소문자·공백·버전 구두점을 정규화한다. '언제', '열리지', '알려줘' 같은 단순 질문 표현을 제외하며, '얼리'는 앞서 해보기에 대응한다. '마감'·'종료' 검색은 기간의 끝을 선택한다. 모든 자연어를 해석하는 기능이나 인터넷 검색은 아니다.

날짜만 확인된 출시일에는 시각을 추가하지 않는다. 검색은 공개 일정의 날짜·확실성·출처를 그대로 표시한다. 결과는 최대 200개이며 입력과 Events/오늘 날짜가 바뀔 때 다시 계산한다.

`JumpToSearchResult`는 기존 단계별 날짜 이동을 사용한다. 검색으로 연 숨김 항목은 원본과 단계 ID를 기준으로 일별 팝업에만 추가 표시한다. 검색어는 로컬 상태에 저장하거나 외부로 전송하지 않는다.

## 검증

Core: 부분 제목·공백 없는 제목·버전·간단한 질문·얼리 별칭·정식 출시 우선·마감 선택·공지 게시일 제외·날짜 미정·빈 결과·사용자 분류.

실제 Model: 현재 월 밖의 실제 번들 출시일 검색, 정식 출시/앞서 해보기 분리, 숨김 항목 발견, 정확한 날짜/단계 이동, 표시 설정 보존.

Native ImGui: 3개 배율에서 검색 버튼으로 열기, 한국어 실제 입력, 원문 링크 버튼의 올바른 URL 전달, 검색 결과 실제 클릭 후 닫기, Enter 이동, 숨긴 항목 팝업, 검색 지우기, Escape/바깥 클릭 닫기를 검사한다. 3개 창 크기의 실제 뷰포트 안에 팝업이 머물며 빈 검색과 결과 표시 사이에도 달력 좌표·행 높이가 유지되는지 확인한다. 3개 테마·창 크기·배율에서 월 탐색과 5개 도구의 첫 줄 배치, 작은 날짜 칸의 일정 제목 보존도 검사한다. 원문 링크 검사는 테스트 콜백으로 전달 URL을 확인하며 브라우저를 실행하지 않는다. 테마/크기/배율별 선택 칸의 네 변이 실제 DrawData에 그려지는지, 팝업 뒤와 닫은 뒤에도 테두리가 유지되는지 검사한다. 최소 창에서 검색 결과의 선택 칸이 전부 보이도록 스크롤하는지와 오늘 버튼의 비율·실제 이동을 확인한다. 현재 native UI 검사는 총 863개다.

`--preview`는 실제 Model과 UI의 `calendar-search`, `calendar-search-date`를 캡처한다. 날짜 이동 미리보기 역시 결과 클릭으로 연다.
