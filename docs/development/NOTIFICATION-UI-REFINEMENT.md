# 알림 화면·분류 정책 정리 · 0.3.1

이 문서는0.3.1 당시 기록이다. 독립 설정 창·반복 등록·새 알림 기본 꺼짐 등 최신 동작은 [0.3.2 보고](RELEASE-READINESS-2026-11-14.md)와 [알림 문서](NOTIFICATIONS-AND-CATEGORIES.md)를 따른다.

2026-11-13. 사용자 피드백을 반영한 결과다. 이전 보고보다 이 문서와 [최신 사용법](NOTIFICATIONS-AND-CATEGORIES.md)이 우선한다.

| 요청 | 반영 |
| --- | --- |
| 알림 내역의 큰 모달과 흰 배경 제거 | 종 버튼이 메인 화면의 알림 내역을 연다. 빈 목록에 불필요한 페이지 버튼을 표시하지 않는다. |
| 목록에서 설정 상태 확인·켜기·끄기 | 분류별/일정별 목록에 현재 시점과 상태를 표시하고 체크박스로 즉시 변경한다. 끈 상태에서도 이전 시점을 보존한다. |
| 어려운 시작 전·마감 전 표현 | 약속 시각, 이용권 만료, 이벤트 시작·참여 종료, 점검 시작·종료, 판매·구매 기한 등으로 구분한다. 점 일정에는 종료 설정이 없다. |
| 세부 설정도 모달 제거 | 화면 안에서 편집하고 저장·취소 후 목록으로 돌아간다. 작은 창에서 본문은 스크롤하고 저장은 보존한다. |
| 공격대 아이콘·기본 분류 | 공격대(여러 사람), 교차 검, 방패 아이콘을 선택기에 추가한다. 기본 공격대 분류는 최초 한 번만 생성한다. |
| 추가 분류의 표시 일관성 | 모든 분류가 같은 아이콘·이름·색상 점 표시를 사용하고 이름 행은 클릭 동작이 없다. |
| 삭제 위치 정돈 | 사용자 분류 행의 `-` 버튼이 이동 대상과 일정 수를 확인한다. 분류 편집 폼의 중복 삭제 버튼은 제거한다. |
| 개인 일정도 삭제 | 기본 개인 일정도 실제 사용자 분류로 분리한다. 기본 개인 일정과 공격대 모두 삭제해도 재생성하지 않는다. |
| 미분류 실체 | CategoryId가 빈 문자열인 상태. 추가·수정에서 ‘미분류 (분류 없음)’를 항상 선택하며 달력·표시 필터·기본 알림 목록에 실제로 나타난다. 분류 삭제 시 다른 분류로 이동하거나 미분류로 보관한다. |
| 시간 표시 | 시간 지정 일정의 달력 표식 앞에 HH:mm을 표시한다. 날짜만 있으면 00:00 같은 시각을 만들지 않는다. 마감은 저장된 경계 시각을 표시한다. |
| 불필요한 링크 장식·툴팁 | 날짜 카드의 외부 링크 화살표·메뉴 안내 툴팁과 달력 표식의 ‘클릭하면 이 날짜의 일정을 봅니다’를 제거한다. 공식 안내는 명시적인 메뉴로 유지한다. |
| 숨김 메뉴의 범위 혼란 | 직접 등록한 일정에는 관련 행사 숨김을 제공하지 않는다. 공개 일정은 같은 카드 전체와 ‘이 중 한 일정만’을 구분하고, 관련 범위가 더 넓을 때만 전체 행사 숨김을 제공한다. |

공개 묶음은 분류가 같다고 생성하지 않는다. 점검·패치는 버전·날짜·공통 공식 근거가 맞는 고유 대응만 묶으며, 구매 캠페인은 검토한 동일 상품의 자료 집합이다. 메뉴에도 해당 기준을 표시한다. 공격대 등 로컬 분류는 이 관계 알고리즘에 포함하지 않는다.

이전 개인 일정 분류는 기존 일정 ID를 바꾸지 않고 `user:default-personal`로 옮긴다. 기존 색상·아이콘·분류 기본 알림·숨김 선택을 보존하며 개별 알림과 영수증은 유지한다. 원래 미분류와 개인 분류를 구분하지 않던 저장값은 기존 개인 분류로 취급한다. 분류 삭제는 선택한 목적지의 기본 알림을 상속하며 명시적인 개별 예외가 우선한다. 유효하지 않은 목적지는 삭제하지 않는다.

검증: Core245 / Infrastructure201 / Model133 / Native513 / 수집117 / CLI30 = 1239개, 한국어 리소스222개 및 게시→수신→손상 유지→재시작 통합 smoke. Native는 실제 MainWindow를 1/1.5/2배율로 실행하며 모달 없는 내역/설정, 목록 토글과 시점 보존, 삭제 취소/확정, 기본 개인 분류 삭제, 시각 표식과 로컬 숨김 메뉴를 검사한다. Model은 마이그레이션과 지정 목적지 이동·미분류 독립·재시작을 확인한다.

실제 DrawData의 차콜1060×780·미드나이트620×480/2배율 화면을 시각 검토했다. 게임 GPU·글꼴/DPI·실제 채팅 전달은 인게임 확인이 필요하다. 원격 게시나 게임 자동 재로드는 하지 않는다.
