# 설정 정리와 아이콘 미리보기

2026-11-13 · 로컬0.2.8.0. 앞선 분 단위 충전·이용권 초기화를 포함한다.

- 테마는 한 줄 선택으로, 일정 업데이트와 이용권은 나란히 배치한다. 확인 주기와 지금 확인의 높이를 맞추고 한 줄로 배치하며, 마지막/다음 확인은 간결하게 표시한다. 좁은 창은 줄바꿈한다.
- 전장 수동 갱신 버튼과 상시 설명 줄을 제거했다. 전장 정보 받기 체크와6시간 자동 확인·제공자 툴팁을 남겼다. 기존 내부 수동 요청 API는 보존하지만 설정 화면에서 호출하지 않는다.
- 일정 색상 및 아이콘은 접지 않는 독립 섹션이다. 넓은 창은2열·4행, 좁은 창은1열·8행으로 표시한다. 각 항목의 분류 아이콘·색, 선택한 아이콘, 색상 편집을 같은 행에 놓는다.
- 아이콘 선택기는 닫힌 상태와 펼친 목록에 모두 실제 아이콘을 그린다. 기본값도 해당 분류의 기본 모양을 보여준다. 아이콘 변경은 색상 설정을 유지한다.
- 개인 일정/이용권 편집창의1시간 전 알림 선택은 설정의 알림 섹션으로 이동했다. 기존 선택을 보존하며 일정 수정/충전 때 알림을 재설정하지 않는다. 시각이 없는 대상은 시각 등록 필요를 표시한다. 과거에 비활성 상태로 저장한 알림도 다시 선택할 수 있게 하고 기존 알림 시점을 보존한다.

알림 설계 권장안은 상단 종 버튼에서 미확인/내역을 확인하고 설정에서 대상·시점·채팅 출력을 관리하는 것이다. 현재 구현한 것은 기존 개인/이용권 알림 설정의 이동이다. 종 버튼/내역, 새 공지 구독, 선택한 공개 일정 등록과 다양한 사전 알림 시점은 이번에 구현한 범위가 아니며 사용자와 계속 협의한다.
