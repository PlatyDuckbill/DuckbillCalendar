# 사용자 요청 대조와 실제 적용 범위

2026-11-13 · 로컬 개발판0.2.6.0. 문서상 완료 표시만 재사용하지 않고 현재 UI·모델·수집 코드와 검사 결과를 대조했다.

## 이번에 빠졌거나 잘못 처리한 부분

1. **시간 단위 충전 미구현**: ‘시간’을 최종 만료 시각 지정으로 잘못 해석했다. 이번에 추가 기간을 `일 + 시간`으로 입력하도록 수정했다. `0일 6시간`, `30일 6시간`, `0일 36시간` 모두 지원한다. 기존 활성 만료일에 더하며, 최초/만료 후에는 현재 시각부터 계산한다. 날짜만 저장된 활성 이용권은 기존 시각을 입력받아 기준을 정하고, 자정으로 추정하지 않는다.
2. **시간 충전 후 잔여 표시 누락**: 기존 목록은 날짜 차이만 표시하므로 몇 시간 남음과 오늘 이미 만료됨을 구분하지 못했다. 등록된 시각으로 잔여 일·시간·분과 실제 만료 여부를 표시하도록 보완했다. 날짜만 있으면 ‘시각 미등록’을 명시한다.
3. **마감 가시성 부족**: 제목 앞 `[마감]` 문자열은 일반 제목과 섞이고 제목 너비도 줄였다. 독립된 주황색 마감 배지/붉은 만료 배지와 여유 있는 표식 높이로 변경했다. 좁은 칸은 같은 경고색의 `!` 표식으로 축약하고 툴팁에서 의미·제목·기간을 모두 보여준다. 점검 종료는 마감과 구분한다.

현재 설치의 저장된 일정 설정도 읽기만 해 확인했다. 일정 업데이트 켜짐/60분, 전장 수신 켜짐, 날짜 칸 전장 꺼짐이다. 사용자 개인 일정·이용권·알림 내용이나 저장 설정은 변경하지 않았다.

## 완료로 취급하지 않는 부분

- **운영 수집기 적용**: 공지/패치 수집 개선과 안정 단계 ID 보강은 로컬 코드·검사에 있다. 원격 source/data/Release에 게시하지 않았다. 기존 원격 수집기가 이 변경을 이미 사용한다고 볼 수 없다. 번들96건과 이전 실수집99건도 구분한다.
- **실제 게임 최종 검증**: 현재 DLL 빌드와 native 화면 검사는 수행했지만 모든 게임 콘텐츠/전투/임무/폰트/DPI를 직접 조작해 검증한 결과는 아니다. 게임 재로드는 사용자가 수행한다. 로컬 빌드와 인게임 적용을 같은 완료 단계로 보고하지 않는다.
- **알림 패널/새 공지 알림**: 협의 중이었고 이번 지시로 보류했다. 구현/완료 목록에서 제외한다.
