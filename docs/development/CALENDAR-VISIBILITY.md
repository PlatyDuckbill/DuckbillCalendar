# 체크박스 캘린더와 시작·종료 기본 표시

2026-11-13 사용자 요청을 반영했다.

달력의 ‘표시할 캘린더’에서 이벤트/패치·출시/점검/PvP/대회/할인·판매/이용권/개인 일정/공지 게시일을 체크박스로 독립 선택한다. 여러 종류를 동시에 선택하고 전체 선택·모두 숨기기를 사용할 수 있다. 체크박스는 종류별 색상을 사용하며 좁은 창에서는 다음 줄로 이동한다.

선택은 로컬에 자동 저장한다. 숨긴 종류는 달력·주요 일정·미정 목록에서 함께 숨기며 원본 데이터·새소식·알림 선택을 삭제하지 않는다. 공지 게시일과 대회 실제 기간은 별도 그룹이다. 새소식의 단일 분류 검색은 달력 체크박스를 덮어쓰지 않는다.

기본은 시작일·종료일 마커다. 기간 중간 날짜에는 막대를 그리지 않는다. 달력 상단 또는 설정의 ‘기간 막대로 보기’를 켜면 이전처럼 연속 기간을 볼 수 있다. 이전 버전의 기본-on 설정은 한 번 시작·종료 표시로 전환하고, 새 UI에서 명시적으로 선택한 막대 옵션은 재시작해도 유지한다. 표시 변경은 실제 날짜와 알림 설정을 변경하지 않는다.
