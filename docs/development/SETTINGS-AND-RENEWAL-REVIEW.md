# 설정·충전·마감 표시 보정

2026-11-13 · 로컬 개발판0.2.5.0.

- 전투/임무 창 숨김과 수동 열기 예외, 편집창 자동 재개 코드를 제거했다. 게임 상태 정책은 자동 요청 보류만 담당하며 창 상태를 바꾸지 않는다. 기존 숨김 설정 키는 엄격한 JSON 복원 호환용으로 읽고 버리며 다음 저장에서 제거한다.
- ‘공개 일정 자동 갱신’은 ‘일정 최신 정보 받기’로 변경했다. 새 설치/누락 필드의 기본은 켜짐이고 기존 false는 유지한다. 끄면 새 일정/변경 사항이 반영되지 않는다는 경고를 상시 표시한다. 빈 주소도 기존 transport와 동일하게 승인된 기본 endpoint로 해석한다.
- 일수 추가 화면에 선택적인 만료 시각 입력을 추가했다. 기존 만료일/현재에서 일수를 계산한 뒤 명시한 시각만 한국 시간으로 적용한다. 미지정이면 원래 날짜/시각 정밀도를 유지한다. 저장 전 결과를 표시하고 잘못된 시각·0일·범위 초과는 거부한다. 종류를 바꾸면 이전 종류의 시각 덮어쓰기 선택을 초기화한다.
- 이용권 만료의 기본색을 경고색으로 변경했다. 사용자 지정 색상은 유지한다. 달력에는 `[만료]`, 이벤트에는 `[마감]`, 점검 완료에는 `[종료]`를 표시한다. 마감 표식은 배경과 왼쪽 선도 강조한다. 기간 중/시작을 마감으로 표시하지 않는다.
- 알림 기능은 기존 구현을 유지하며 확장 구현 전 협의 중이다. 요청 대상은 새 공지·개인 일정·이용권 만료·사용자가 선택한 공개 일정이다. 종 버튼의 미확인 개수·내역 패널·알림 설정 연결을 제안했으며 표시 채널/만료 사전 알림 시점은 미정이다. 새 공지는 첫 동기화를 기준점으로 삼고 이후 새 글부터 알리는 안을 제안했다. 이 패널이나 새 공지 알림이 이미 구현됐다고 보고하지 않는다.

검증: Core200 / Infrastructure185 / Model95 / native UI396 / 수집117 / CLI30 =1023개 검사, 한국어 리소스222개와 별도 게시/소비자/손상/재시작 통합 smoke. 새 기본 설정의 실제 모델 요청·저장된 끄기 복원·제거 설정 호환, 날짜/시각 충전과 native 입력/잘못된 시각 거부를 확인했다. 차콜1000×720와 미드나이트620×480/2배율의 실제 DrawData PNG를 확인했다. 실제 게임 조건/글꼴/DPI 확인은 별도다. 원격 source/data/Release 게시를 수행하지 않았다.
