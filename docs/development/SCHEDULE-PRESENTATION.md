# 전체 일정 표현과 화면 밀도 개선

2026-11-12. 공식 공지·패치·PvP·확장팩·얼리 액세스·할인 기간을 같은 달력에서 다루도록 실제 Plugin UI를 개선했다. 상단 달력/새소식/이용권/설정 탭을 유지하며 별도 PvP 탭을 추가하지 않는다.

## 달력과 주요 일정

- 상단 년월을 누르면 2027년 2월 같은 미래 달로 직접 이동한다. 입력 범위는 2020~2100년/1~12월이다.
- 넓은 화면에서는 우측에 주요 일정5개를 표시하고 전체 목록은 고정 크기 팝업에서 스크롤한다. 좁은 화면에서는 달력 아래로 배치한다.
- 이벤트 전체 phase의 시작과 마감을 정렬한다. 판매·할인은 마감 우선이며 출시·얼리·점검·PvP와 대회의 신청/예선/결선도 별도 항목이다. 항목을 누르면 해당 월/날짜/phase를 정확히 선택한다.
- 공식 출시 날짜만 알려졌으면 날짜+시각 미정, 얼리 액세스처럼 시각까지 명시됐으면 KST 시각을 표시한다. 예정/추론 qualifier를 보존한다. 미발표 날짜는 달력에 만들지 않고 미정 목록으로 남긴다.
- 공지 게시 phase(published/공지 게시)는 기본 달력에서 숨기고 새소식에 남긴다. 공지 표시 옵션 또는 공지 필터를 고르면 게시일도 표시한다. category가 notice여도 CCRC의 실제 선발/신청/예선/결선 phase는 숨기지 않는다.
- 주간 높이는 폰트17px에서 약80~104px이다. 최대3개 막대와 하루1개 지점을 우선 표시하고 나머지는 +N으로 선택한 날 목록에서 확인한다.
- 패치/점검/PvP/판매/게임/시즈널/웹/개인을 색으로 구분한다. 막대에 분류, 점 항목에 phase 이름을 먼저 표시해 얼리와 정식 출시를 구분한다.
- 원문 재검토 대기 marker가 있으면 달력·주요 일정·상세에 재확인 필요를 표시한다. 상단은 최신 수집 시각이며, 모든 출처가 동시에 최신이라는 의미로 표현하지 않는다. 상세의 항목별 관측 시각과 원문을 확인한다.

## 새소식·이용권·설정

새소식은 날짜/분류/제목3열의 스크롤 표와 우측 상세 패널로 구성한다. 상세는 제목·분류·원문 버튼·관측 시각·phase별 시작/종료를 먼저 보여 준다. 긴 원문 메모와 출처는 접고 알림 선택도 별도로 접는다. 상세 높이를 제한해 긴 원문이 창 밖으로 늘어나지 않는다.

빈 이용권 화면은 제한된 크기의 안내 카드와 추가 버튼을 표시한다. 등록 후에는 제목/만료일/남은 기간/수정 표를 제공하며 오늘 만료·만료·D-N을 구분한다.

설정은 일반 표시/알림과 데이터 수신을 가변1~2열로 보여 준다. 긴 설명은 툴팁, 예시 모드·파일 가져오기·URL·raw status·health는 고급 데이터/진단에 둔다. 원격 수신 토글은 고정 공개 주소로 자동 저장한다. 열 수가 바뀔 때 별도 table ID를 사용해 native ImGui 측정에서 발견한 높이 증폭을 막았다.

## 확인

- 실제 CalendarModel32검사(기존19+13): 미래 년월 이동, 2/19 얼리와2/23 출시의 별도 marker/precision, 정확한 phase 선택, 공지 게시 숨김과 대회 phase 보존, 시작/마감 정렬, 미발표 PvP 날짜 미생성.
- 실제 native ImGui66검사(기존30+36): 한국어 폰트와1/1.5/2배율, 기존 모달/툴팁 회귀, 실제96건 번들의 확장팩 이동·별도 marker, 주간 높이 제한, 760/1180/1600px에서 뉴스 상세/설정/빈 이용권 영역의 크기 제한.
- 한국어/영어177개 리소스 쌍 검증, 관련 프로젝트 경고0/오류0.

GPU·실제 게임 스크린샷 검증은 별도다. 위 검사는 게임 프로세스나 네트워크를 실행하지 않는다.

후속 폭 검사에서 상단 버튼·검색/분류/알림 필터도 실제 widget 너비와 row 잔여폭에 따라 줄바꿈하도록 보완했다. 760/1180/1600px ×1/1.5/2배율의 경계9검사를 추가해 native 검사는75개다. 확장팩 얼리/정식2건은 주요 일정에서 우선 고정하고 나머지3건을 가까운 일정으로 채운다.
