# 하우징 청약: 외부 한국 서버 주기와 달력 표현

0.4.0.0 기능. 주기 자료 확인일: 2026-11-14.

## 날짜의 출처

사용자가 외부에서 확인한 패턴 적용을 허용한 뒤, [에테르웨이 캘린더](https://aether-way.com/calendar)의 공개 구현을 다시 확인했다. 해당 페이지가 사용하는 [공개 스크립트](https://aether-way.com/_next/static/chunks/1lap-4tlxi2e1.js)의 `housingPieces`는 한국 시간 2026-05-01 00:00을 신청 시작 기준으로 사용하고, 신청 5일·결과 4일을 반복한다. 2026-11-14 확인.

`HousingLotterySchedule`은 이 출처의 기준과 주기를 별도로 구현한다. 게임 탭을 여는 조건이나 화면 문구 인식에 의존하지 않는다. 날짜 칸과 현재 단계, 다음 회차는 같은 계산을 사용하고 KST 자정에서 전환된다. 출처 기준일 전 날짜는 채우지 않는다.

이는 외부 캘린더 주기를 적용한 값이다. 게임 서버를 실시간 조회하거나 해당 회차를 공식 확인한 자료로 표시하지 않는다. 팝업에 출처·확인일·주기 출처 링크를 제공하며 운영 변경 시 게임 내 표시와 공식 공지가 우선함을 안내한다.

[한국 공식 토지 추첨 안내](https://www.ff14.co.kr/news/notice/view/2198)는 5일/4일 반복, 당첨자의 구매 확정, 점검에 따른 실제 이용 시간 차이의 설명에 사용한다.

## 달력 표현

일반 이벤트·개인 일정은 기존 위치인 날짜 칸 위쪽에 표시한다. 하우징은 아래쪽 한 줄로 신청/결과 단계를 표시하며 배경색은 옅게 유지한다. 반복되는 두 줄 설명, 날짜 칸 전체의 진한 강조와 마감일 테두리는 사용하지 않는다.

오늘·내일 마감은 아래 한 줄의 작은 배지로 강조한다. 자정 마감은 그 직전 실제 참여 가능한 날짜를 마감일로 취급한다. 날짜 클릭은 기존 팝업을 열어 정확한 마감과 출처를 보여준다. 표시 메뉴에서 끄면 배경색·문구·요약을 모두 숨긴다.

하우징 때문에 달력 행의 최소 높이나 일반 일정의 시작 위치를 바꾸지 않는다. 하단 한 줄 공간만 확보하고 남은 일정은 기존 더 보기로 연다.

## 설명 창

하우징 설명은 최대 29글자 크기의 명시적인 폭을 사용하고 화면 너비가 좁으면 여백을 제외한 화면 폭으로 줄인다. 창 높이는 화면 안으로 제한하고 팝업 위치도 화면 안으로 맞춘다. 고정 폭 없이 자동 크기와 줄바꿈만 결합해 창이 버튼 너비로 수축하던 문제를 제거했다.

현재 단계·마감, 짧은 기간, 5일/4일 흐름, 출처와 필요한 안내만 남겼다. 출처/공식 안내 버튼은 공간이 있으면 한 줄에 놓인다. 일반 툴팁도 화면 폭을 넘지 않도록 줄바꿈 폭을 제한한다.

## 저장과 검증

표시와 스타일은 기존 로컬 설정을 사용한다. 과거 개발 구현이 저장했던 `HousingObservations`는 구형 파일 호환을 위해 읽되 외부 주기를 게임 관측으로 새로 저장하지 않는다. 공개 feed·새소식·개인 일정·시간 알림에는 하우징 이벤트를 추가하지 않는다.

Core는 외부 기준일, 5일/4일 경계, 자정·오늘/내일 마감, 월 전체·연말·윤년을 검사한다. Model은 게임 화면을 열지 않은 새 상태·재시작·월 이동·단계 전환·표시 끄기를 검사한다. Native ImGui는 날짜 클릭과 표시 끄기, 1/1.5/2배율 및 620×480·1320×1050 뷰포트의 설명 창 폭과 화면 내 배치를 확인한다.

`--preview`의 `housing-calendar`, `housing-details`, `housing-day`는 별도 하우징 데이터를 주입하지 않고 실제 Model과 UI로 그린다. 미리보기의 현재 시각만 재현 가능한 검사용 시각으로 고정한다.
