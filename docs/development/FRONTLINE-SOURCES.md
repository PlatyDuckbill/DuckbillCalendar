# 한국 전장 일정 수신

2026-11-13 갱신.0.2부터 [에테르웨이 전장](https://aether-way.com/frontline)이 사용하는 공개 HTTPS API `https://api.aether-way.com/api/v1/frontline/schedule?month=YYYY-MM`에서 한국 날짜별 일일 도전 맵을 가져온다. 응답의 date/startsAt/endsAt/name/subtitle을 사용한다. 한국 클라이언트에서 관측한 값이나 공식 검증 규칙으로 표시하지 않는다.

실수신에서2026-11-13은 연습전/워코 치테,11-14는 쟁탈전/봉인된 바위섬이었다. 이전처럼 기준일을 찾지 못해 전체를 ‘확인 불가’로 두는 구현을 대체한다. 제공되지 않은 날짜를 단순 회전으로 계산하지 않으며, 현재 월·내일이 속한 월·보고 있는 지원 범위 월만 요청한다.

## 수신과 실패 처리

- 전장 수신 기본 켜짐. 설정에서 끌 수 있다. 달력의 전장 요약은 제공 사이트로 연결된다.
- 0.2.2부터 오늘·내일을 한 묶음으로 표시한다. 날짜 칸의 맵은 기본 끄고 표시 메뉴의 ‘날짜 칸에 전장 표시’에서 켠다. 수신 여부와 날짜 칸 표시는 별도 설정이며 날짜 팝업의 해당 날짜 전장 정보도 유지한다.
- HTTPS 고정 host/path. 인증·쿠키·자동 redirect 없음. 요청 내용은 공개 월뿐이며 개인 일정·캐릭터·계정은 포함하지 않는다.
- 응답 최대64KiB,15초 제한. JSON 형태·해당 월 전체 날짜·날짜 중복·KST 자정/24시간·알려진 한국 맵/모드 조합을 검증한다.
- 6시간 내 동일 월 재수신 없음. 실패 시15분 재시도.6시간 이상 된 값은 저장본으로 구분하고24시간을 초과하면 표시하지 않는다.
- 0.2.3은 캐시 읽기/파싱/HTTP를 작업 스레드에서 수행한다. 끄면 진행 요청을 취소하며 취소를 장애로 처리하지 않는다. 429/503의 Retry-After가15분보다 길면 그 시각까지 기다린다. 월이 바뀌면 제공 범위 밖 메모리 캐시를 제거한다.
- 검증한 월을 AtomicJsonStore로 저장하고 재시작 시 유효성을 다시 검사한다. 제공 범위 밖이나 누락된 날짜에 가짜 맵을 채우지 않는다.
- 공식 검증 회전 규칙을 담는 Core의 FrontlineRules 계약은 별개다. 커뮤니티 API 응답을 verified rule로 바꾸지 않는다.

## 검증

실제 수신: `dotnet run --project tests/DuckbillCalendar.Infrastructure.Checks -- --frontline-live`.

오프라인 검사는 실제2026-11 응답을 [fixture](../../tests/DuckbillCalendar.Infrastructure.Checks/Fixtures/frontline-2026-11.json)로 고정했다. 정상 날짜·오늘/내일·잘못된 reset/map/month·누락/중복·redirect/type/size/JSON 오류·갱신 간격·저장본 만료·캐시 재시작을 확인한다. 스크린샷 렌더에서는 이 fixture만 사용한다.

공식 [한국 전장 가이드](https://guide.ff14.co.kr/pvp/sub04)와 과거7.4 자료는 자정 변경/개최 규칙의 참고 자료다. 제공 사이트의 달력 응답은 공식 게임 UI와 실기로 대조한 결과가 아니다. 서비스 중단·규칙 변경 시 수신을 실패 상태로 처리하고 기존24시간 제한을 따른다.
