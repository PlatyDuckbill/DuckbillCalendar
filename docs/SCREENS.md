# 화면 구성과 동작

목업 진입점: [mockup/index.html](../mockup/index.html). 2026-11-11 20:00 KST를 고정 시각으로 사용한다. `예시` 항목은 실제 운영 일정이 아니다.

## 공통

Dalamud 기본 화면처럼 상단에 달력 / 새소식 / 이용권 / 설정 탭을 한 줄로 둔다. 운영 도구를 설정에서 켜면 데이터 관리 탭을 추가 표시한다. 좌측 메뉴와 독립 전장·PvP 탭은 없다. 탭은 방향키·Home·End로 이동하고 숨긴 탭은 건너뛴다. 제목줄에는 KR·KST와 작은 화면 버튼, 하단 상태줄에는 피드 상태를 둔다. 원격 상태 시뮬레이션은 설정에서만 조작한다.

## 달력

- 상단 요약은 큰 카드 대신 오늘 마감 / 관심 알림 / 이용권 만료를 한 줄로 표시한다.
- 월 이동·오늘·월간/목록 전환. ‘오늘’은 목업의 기준일이다. 선택일을 바꾸면 오른쪽 일별 목록을 바꾼다.
- 종류 필터·검색을 달력과 목록에 공통 적용한다. 시즌·시리즈와 ‘알림 설정 일정’ 필터를 제공한다. 선택이 필터 밖에 있으면 상세에 이를 알린다. 월 목록은 시작·끝이 다른 달인 진행 일정도 기간 겹침으로 포함한다.
- `기간 막대` / `시작·종료만` 옵션을 제공하고 선택을 로컬 저장한다. 기본은 기간 막대다. 기간이 확정된 여러 날짜의 이벤트·할인을 연속 막대로 표시한다. 수령 막대는 설정에서 선택적으로 켜며 기본 off다. 수령 막대를 꺼도 시작·종료 항목, 일별 목록, 오늘 마감 집계와 알림 선택은 유지한다. 주·월 경계에서 이어짐 표시와 함께 나누며, 겹치는 일정은 행을 분리하고 주당 최대 3행을 그린다. 초과는 날짜별 숨긴 phase 수로 더보기 표시한다.
- 시작·종료만 모드에서는 두 경계 날짜에만 짧은 항목을 표시한다. 이용권 만료·개인 일정은 두 모드에서 동일하게 날짜 항목으로 표시한다. 날짜당 2행 초과는 더보기로 일별 목록을 연다.
- 날짜 미정 종료는 임의의 기간 막대로 늘리지 않는다. 알려진 시작일은 날짜 항목으로, 미정 종료는 아래 별도 목록으로 표시한다.
- 막대 모드에서 기간 중간 날짜를 눌러도 진행 중인 일정이 상세 목록에 나온다.
- 개인 일정의 예시·예정 배지를 항상 유지한다. 날짜 미정 항목은 달력 아래 별도 영역에 둔다.
- 일정 클릭 → 오른쪽 상세에서 선택 phase를 강조하고 시각·상태·원문·마지막 확인을 확인. 알림은 phase의 시작·마감을 각각 로컬 선택한다. 미정 마감 선택은 확정 대기이며 실제 알림음은 발생하지 않는다.
- 빈 날짜·필터 결과 없음·피드 오류도 정상 상태로 보여준다.

## 새소식

공지·이벤트·할인·패치의 통합 목록. 실제 공지의 원문 링크와 공개 상태를 표시한다. 목록 클릭은 공통 상세로 이어진다. 게시일은 작은 보조 정보, 기간은 별도의 주요 정보다. 날짜 없는 공지와 실행 일정은 구분한다.

## 달력 하단의 전장·시작일

별도 탭 없이 달력 아래 한 줄에 `오늘 전장 / 내일 전장`을 표시한다. 기본값은 확인 불가다. 설정에서 예시를 켠 경우에만 봉인된 바위섬 / 영광의 평원을 명시적인 배치 예시로 표시한다. 실제 계산은 검증 상태·anchorDate·anchorIndex·순서·validFrom/validUntil이 필요하며 오늘·내일 날짜별 유효 범위를 따로 검사한다. 실제 기준점은 아직 미확인이다.

크컨 시즌과 PvP 시리즈의 시작은 달력의 해당 날짜에 각각 표시한다. 현재 스냅샷은 크컨 시즌 22 시작 11/10, PvP 시리즈 12 시작 9/8이다. 하단 시작일 바로가기는 해당 달·날짜로 이동하고 그 일정 상세를 선택한다. 새 시작일이 공식 확정되면 같은 데이터 경로로 추가한다. 종료일이 미정이어도 시작일 표시는 유지한다. 시리즈 시작 시각은 7.56 점검 완료 공지에 연결한 해석이다.

## 이용권

로컬 계정 별칭과 수동 만료 일시를 보여준다. 예시 정액제는 11/18, 집사 이용권은 11/25다. 수정 버튼으로 종류·이름·종료 일시를 편집하고 달력에 즉시 반영한다. 로컬 목업에서는 계정 프로필 1개를 사용하며 다계정/캐릭터 연결 UI는 차기 구현 범위다. 날짜만 아는 입력은 정식 플러그인의 계약에 포함하지만 목업 폼은 정확한 일시 입력만 시연한다.

## 개인 일정 추가

제목, 종류, 날짜·시각, 메모를 입력한다. 필수값·범위 검증 후 로컬 저장한다. 저장된 기록을 선택하면 수정·삭제할 수 있다. 공지/공개 피드 내용은 이 폼으로 덮어쓰지 않는다. 목업에서 등록한 개인 일정은 모두 `내 일정`이다.

## 데이터 관리

수집→후보→검수→배포 과정을 보여준다. 예시 후보에 ‘검수 완료’ 표시를 하고, 공개 후보 JSON을 다운로드할 수 있다. 검수 표시와 파일 내보내기만 동작하며 실제 배포 상태는 ‘미게시’다. 개인 이용권·개인 일정은 공개 파일에 포함하지 않는다. 원격 갱신 버튼은 없다. 이 화면은 운영자용 도구의 제안이며 최종 일반 사용자 플러그인에서는 숨긴다.

## 설정

Graphite/Paper, 수령 막대·전장 예시·운영 도구 표시, 정상 캐시/오프라인/전체 소스 실패 시뮬레이션, 수집/검수/이 기기 갱신 구분을 제공한다. 목업은 실제 HTTP 수집을 하지 않는다. 설정 변경은 로컬 저장한다. 정식 제품에는 별도로 갱신 동의·도메인·TTL·알림·DPI·언어 설정을 구현한다.

## 작은 화면

우측 하단에 독립적인 부유 화면으로 오늘 마감·관심 일정·만료를 압축한다. 접기/닫기 동작을 제공한다. 정식 Dalamud에서는 별도 WindowSystem 화면으로 만들고 이동·크기·잠금 상태를 보존한다.

## ImGui 이식 지침

달력은 Table 기반 7열, 목록은 clipper 기반으로 구성한다. 기간 막대는 계산된 주별 열 범위·행을 draw list에 그린다. Draw에서는 계산된 view model만 읽는다. 상세와 목록은 선택 event ID를 공유한다. 좁으면 우측 상세를 아래 또는 별도 화면으로 옮긴다. 제목줄 35px, 탭 약35px, 본문 여백 9px, 상세 폭 249px, 날짜 높이 68px+필요한 막대 행으로 압축했다. 기본 980×660 / 최소 760×500을 이식 목표로 하며 인게임 크기는 실기 확인 전이다.

일정·phase·프로필은 stable ID, UI는 `###DuckbillCalendar.*` ID를 사용한다. 폰트·배율·테마는 스코프로 적용하고 다른 플러그인 스타일에 영향을 주지 않게 복원한다. HTML의 CSS 그리드·모달을 임베디드 브라우저로 띄우는 제품이 아니라 ImGui로 다시 구현하는 설계다.
