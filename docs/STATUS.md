## 이번 개발 변경

- 설정의 ‘일정 파일과 백업’은 .ics 내보내기/일정 가져오기와 .json 전체 백업/전체 백업 복원을 각각 한 쌍으로 구분한다. 전용 파일 선택기와 형식 검사를 적용하며, .ics는 현재 프로필에 일정을 추가하고 .json은 전체 개인 자료·설정을 교체한다.
- 일정 UID로 중복을 제외한다. 시작·종료·종일 날짜·메모를 보존하고 가져온 일정 알림은 꺼짐으로 등록한다. 반복 규칙·예외 회차·취소·미지원 형식은 제외 건수를 표시한다.
- JSON 전체 백업은 모든 프로필의 일정·이용권·분류·알림·화면 설정을 보존한다. 복원 전에 현재 자료를 별도 파일로 남기고, 미리보기 이후 상태가 바뀌면 적용을 거부한다.
- 복원 시 오래된 편집과 메모리 알림 대기열을 비우고 과거 받은 알림의 채팅 대기를 복원하지 않는다. 파일 작업은 작업자에서 처리하며 새 의존성과 온라인 동기화를 추가하지 않았다.
- .ics는 설정 백업 형식과 구분한다. 외부 앱의 실제 가져오기 성공은 아직 확인하지 않았다. 종료 시각/UID를 저장한 새 자료는 이전 버전으로 되돌리기 전에 적용 전 보존본을 사용한다. [지원 범위·복구·확인 순서](development/CALENDAR-FILES.md).

## 현재 기능과 환경

- 한국어 전용. 상단 월 탐색·검색·표시·추가·알림·설정, 날짜 상세와 개인 일정/이용권 관리. 현재 테마는 스모크·펄이다.
- 공개 일정·전장은 선택형 HTTPS 수신이며 개인 자료는 전송하지 않는다. 기본 갱신 켜짐, 알림과 로컬 채팅은 새 설치에서 꺼짐이다.
- 공개 일정은 확인 주기·실패 대기·캐시 복원을 적용한다. 전투·임무 중 자동 요청을 미루고 안정15초 뒤 재개한다. [수신](development/LIVE-DATA.md)·[전장](development/FRONTLINE-SOURCES.md).
- 공격대 일정은 요일별 시각을 지정해 유한한 회차를 한 번에 등록한다. 개별 수정과 이번/이후/전체 삭제를 지원한다. 전체 반복 패턴 수정은 이번 범위에 포함하지 않았다. [정책](development/WEEKLY-RAID-SCHEDULES.md).
